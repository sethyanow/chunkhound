- **setup_wizard exempted entirely**: ignore_errors = true per-module override. File has ~33 errors from untyped httpx kwargs and missing annotations — not worth fixing piecemeal.
- **String dispatch → callable dispatch with TypeVar**: The core fix for 90+ no-any-return errors. `_execute_in_db_thread_sync` accepted string operation names, did getattr lookup, returned Any. Changed to accept `Callable[..., T]` with `@overload` so return types flow through. String dispatch kept as backward-compat fallback via overload.
- **Upstream lancedb/duckdb type: ignore**: lancedb `to_list()` returns `List[dict]` (bare), duckdb `fetchone()/fetchall()` returns Any. These are upstream stub gaps, marked with `# type: ignore[no-any-return]` and comment explaining why.
- **assert_never over NotImplementedError**: For exhaustive enum matching on UniversalConcept in parser mappings. Catches missing variants at both type-check and runtime.
- **Stale type: ignore cleanup**: 30 removed, 8 kept (optional dep guards for mcp, pygit2, ryml, psutil, sklearn). The 8 show as unused-ignore when deps are installed locally — that's expected.
