# Session Handoff — 2026-04-06

## Decisions Made

- **LanceDB symbol/edge CRUD uses PyArrow schemas + native API, not SQL adapter.** The existing `execute_query` on LanceDB is a limited SQL-to-Lance shim. All new symbol methods use `table.search().where()`, `table.add()`, `table.delete()` directly. Schemas defined as `get_symbols_schema()` / `get_symbol_edges_schema()` in lancedb_provider.py.

- **LanceDB graph_walk uses Python BFS with visited set + frontier cap (10K).** No recursive CTEs in Lance. BFS expands neighbors per-FQN via edge table queries. Cycle detection via `visited: set[str]`. Frontier capped at 10K to prevent OOM on dense graphs. Same contract as DuckDB's CTE-based walk.

- **`_ensure_symbol_tables` returns (sym_tbl, edge_tbl) tuple.** Refactored from void `_ensure_symbols_table` to return the table refs. All executor methods use locals instead of `self._symbols_table` — eliminates 29 mypy attr-defined errors (mypy can't track cross-method None narrowing).

- **Realtime deletion bug found and fixed.** `add_file()` silently dropped delete events when the file was still in `pending_files` from a queued embed/lsp pass. Fix: `priority="delete"` now discards from pending_files before the dedup check. Regression test: `test_delete_bypasses_pending_files_dedup` + `test_delete_event_flows_through_full_internal_pipeline` (synthetic event pipeline, no OS/watchdog dependency).

- **Flaky e2e deletion test replaced.** `test_service_doesnt_handle_file_deletions` depended on watchdog delivering filesystem events within 3 seconds. Replaced by synthetic pipeline unit test that feeds events directly into `event_queue`. The standalone test was deleted. The qa_deterministic test (which has the same pattern embedded in a larger test) was marked `@pytest.mark.slow`.

- **Integration test tier is misclassified — 864 tests, most aren't integration.** Full inventory captured. Parser tests (325), DB provider tests (95), git/fs tests (113) are all calling live external systems. Real integration tests (multi-module collaboration across internal boundaries) are ~19. This needs a follow-up task.
