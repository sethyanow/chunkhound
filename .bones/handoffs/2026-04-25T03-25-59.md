## Decisions Made
- **Execution shape**: single monolithic bones task (`ch-agj`), executed across 3 checkpoints — Checkpoint 1 = Groups A+B+C (protocol + Voyage + OpenAI), Checkpoint 2 = Group D (TEI + schema + factory), Checkpoint 3 = Groups E+F (call sites + regression). Commit per group (3 commits in Checkpoint 1, 3 planned in Checkpoint 2, 3 planned in Checkpoint 3).
- **Validation symmetry** (major design decision, mid-session correction): dropped the original skeleton's "Voyage validates, OpenAI silently accepts" asymmetry. All providers now call `validate_task(task)` at their **deepest internal method** entry — Voyage at `_embed_single_batch_locked` (line 297), OpenAI at `_embed_batch_internal` (line 697), TEI (pending) will do it in its `_embed_batch_internal` override. Rationale: AI agents write this code; consistency beats forward-compat theoretical cleverness. Three C's framing: Clarity (same pattern everywhere), Cohesion (validator owns the contract), Coupling (providers depend only on the validator).
- **Helper extraction timing**: ignored rule-of-three. `validate_task` lives in the interface module from the start even though a single caller would have worked initially. Explicit user direction.
- **Signature convention**: `task: EmbeddingTask = None` is **always appended at the end** of every signature. Locked in by protocol regression tests (`test_task_is_trailing_parameter`). Positional calls don't shift.
- **OpenAI token-limit recursion**: use `embed_function=lambda batch: self._embed_batch_internal(batch, task=task)` (lambda closure) instead of bare `self._embed_batch_internal` — otherwise `task` would get dropped across recursion. Two regression guards in place (`__name__ == "<lambda>"` + `inspect.getclosurevars` check).
- **Voyage `input_type` mapping**: `None | "passage"` → `"document"`, `"query"` → `"query"`. None-maps-to-document preserves pre-task behavior so existing DB embeddings stay valid (cache identity doesn't include task).
- **mypy narrowing**: use `cast(EmbeddingTask, task)` after the `not in (...)` guard — mypy doesn't narrow through tuple membership.
- **MEMORY.md**: seeded at project root. Long-term knowledge only, **NOT a session diary**. Status and session history belong in `.bones/`. Catchphrase: "see bones for status."
